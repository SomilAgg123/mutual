# Attribution and licensing notes

Mutual originated as a collaborative project by **Somil Aggarwal and Nalu Concepcion**. Both are named contributors in the original repository histories. Some historical commits use machine-account names; this edition does not assign those commits to an individual without evidence.

The portfolio edition is maintained for Somil Aggarwal's personal project collection. It preserves the original collaborators' work and adds consolidation, sanitization, a standalone matching implementation, examples, tests, and documentation. It should not be presented as solely authored by one person.

The old frontend package manifest contained an `ISC` label, but neither original repository included a project-level license file. This edition does not introduce a blanket open-source license for the collaborative code or branding. Contributor rights and any future licensing choice remain separate from the ability to inspect this repository.

Bundled Lato font files retain their original [SIL Open Font License notice](frontend/assets/fonts/OFL.txt), including the font author's attribution. Unverified third-party font files and portrait photos were omitted from this edition. Generated placeholder avatars are identified in [the asset inventory](docs/assets.md).

[Preservation provenance](docs/provenance.md) records the original source snapshots and import decisions.
