# Preservation record

The portfolio edition was assembled on 23 November 2026 from two local Git checkouts. Their original source, branches, working-tree changes, and complete histories remain in those checkouts; the new repository imports sanitized files without importing their Git histories.

| Source | Selected snapshot | Original history at that snapshot |

The [import manifest](import-manifest.json) records full commit IDs and paths selected for import. It is a selection record, not a claim that imported files are byte-identical after sanitization. Subsequent documentation, maintained code, generated avatars, and tests are additions to this edition.

The original frontend also had a local Xcode-project modification. Its current source configuration was included where applicable, with signing identity removed. Backend working-tree differences were generated bytecode and were not imported.

## What was retained

- All original application JavaScript/JSX source, including the 29 screen files, contexts, hooks, and shared components.
- The Flask routes, data models, processors, sockets, original algorithm, enums, and migration scaffold.
- The native project source, app branding, splash artwork, and licensed Lato font files.
- The original weight values and lookup matrices, also reused by the new standalone scorer.
- Named contributor attribution, with a new history for the curated edition.

## What was changed or omitted

- Secrets, real contact placeholders, old deployment endpoints, local machine paths, and native signing identity were removed or replaced.
- Git histories were not copied because committed source contains credentials and generated environments. Do not copy the old `.git` directories into this repository.
- Installed dependencies, bytecode, logs, installers, environment files, obsolete lockfiles, signing material, and the binary Gradle wrapper were omitted.
- Trailing whitespace was cleaned from imported text files, with Git text normalization configured for the new repository.
- The frontend dependency list was reduced from 630 entries to 30 packages referenced by application/configuration code. It is a curated historical manifest, not a validated modern build environment.
- Browser review captures use eight original screens with offline fixtures. Small declaration-order and variable-scope fixes in the captured screens and score-circle component allow rendering without redesigning layouts; see [screenshot provenance](screenshots/README.md).
- Portrait photos and unverified font binaries were omitted as described in [assets](assets.md).
- The historical Flask app is disabled by default and no longer creates database tables at startup. Its wider application behavior remains historical.
- The runnable scoring implementation has corrected and documented semantics; the original algorithm remains available for comparison.

## Saved branches reviewed

Branches with commits not reachable from the selected snapshots were examined before choosing the import baseline.

| Branch | What it contains | Decision |
| --- | --- | --- |
| Frontend `onboarding5` | Early multi-image upload experiment using a different picker and auth-context API | Keep the later onboarding/profile screens; retain this unfinished experiment only in the original history |
| Frontend `somil/fetch_statements` | An extra context file containing draft fetch wrappers, unresolved identifiers, and Python-style `str(...)` calls in JavaScript | Keep the existing integrated screen/context code; do not introduce a duplicate broken API layer |
| Frontend `origin/somil/image_gallery` | Earlier carousel experiment on an obsolete Home screen, with unavailable photo references and a missing Image import | Keep the later Source and Profile photo UI |
| Frontend `origin/nalu/profile` | Earlier native build configuration work | Do not replace the selected snapshot's native scaffold |
| Backend `nalu/websockets_woo` | Older session-ID-based socket experiments and query changes | Keep the selected snapshot's later user-ID-based message routes and socket handling |

No additional complete product feature was recovered from these differences. The original branches remain available for future archaeology; they were not deleted, merged, or rewritten.
