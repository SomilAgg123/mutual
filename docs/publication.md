## Published scope

Only the curated repository and a static site built from it are published. Original repository histories, environments, credentials, and unverified portraits are excluded. Collaborator attribution and asset notices are retained; no new blanket license has been assigned.

The website renders the original screens with browser adapters and offline fixtures. It does not deploy the Flask API, enable authentication, send messages, upload photos, or create introductions. Its score explorer displays output generated by the maintained Python demo during the build.

The [Pages workflow](../.github/workflows/pages.yml) builds and tests the site on pull requests, and deploys successful builds from `main`. Repository visibility and Pages configuration are managed on GitHub. [Site development notes](../site/README.md) describe local reproduction.

## Verification boundary

Publication checks cover the curated files and reachable published history. The targeted scanner reports selected credential patterns without printing values. No original cloud-account changes were made; removing old credentials from this edition does not revoke credentials stored in the original repositories.

The scanner is not a full security audit. The historical API remains disabled by default and is not part of the GitHub Pages deployment.
