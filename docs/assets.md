# Asset inventory

| Assets | Provenance / treatment |
| --- | --- |
| `frontend/assets/icons/`, splash backgrounds, native app icons | Imported from the original Mutual checkout as project branding. No separate asset license was supplied; the project attribution in NOTICE applies. |
| `frontend/assets/graphics/delete.png`, `frontend/assets/images/empty_chats.png` | Original project UI artwork, retained with the same provenance limitation |
| `frontend/assets/fonts/Lato-*.ttf` | Original bundled Lato files, with their accompanying OFL notice retained verbatim |
| Other `frontend/assets/images/*.png` | New anonymous geometric avatar placeholders, generated by a committed script |
| Original portrait JPEGs | Omitted because source/permission records were not available; originals remain in the source checkout |
| Original SeoulHangang font files and sample image | Omitted because no accompanying license was found in the supplied checkout; UI aliases now resolve to Lato |
| `docs/screenshots/*.png` | Browser captures of the original components with documented adapters, and actual output from the maintained Python example |

Regenerate the placeholder avatars from the repository root:

```sh
python3 scripts/generate_placeholders.py
```

The script uses only the Python standard library and geometric shapes. Historical basenames are retained so the original screen structure stays recognizable; the files do not depict the people or scenes implied by those names.

The review captures do not claim a working native application. Their [provenance and regeneration steps](screenshots/README.md) describe the rendering adapters and fixture data. The README also uses the original project icon; screen implementations can be inspected through the [frontend source tour](../frontend/README.md).
