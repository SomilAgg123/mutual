# Backend source

- [matching](matching): maintained, dependency-free Python scoring package used by the CLI and tests.
- [prototype](prototype): sanitized historical Flask application, retained for code inspection.

Run `python3 examples/match_demo.py` from the repository root. Neither Flask nor the historical cloud services are needed for that command.

See [architecture](../docs/architecture.md) and [scoring rules](../docs/matching.md) for the relationship between the two implementations.
